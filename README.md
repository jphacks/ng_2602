## 行き場のない気持ちに対する共感を目的としたWebアプリ
### 「他人の目を気にせずに気持ちを吐き出したい」<br>「行き場のない気持ちに対して誰かが共感してくれる場が欲しい」<br>現代のSNSには適さないけど誰かに聞いてほしい、そんな思いを抱えた人が多くいるはず。<br>この悩みを解決するWebアプリを目指します。
### 共感してほしい出来事とそれに伴う感情を入力、日記として記録します。記録した出来事は任意で公開することができ、ユーザー間でリアクションをとることができます。
### 特長
#### 1. 出来事をその感情によって分類することで、自分の気持ちが整理できます。
#### 2. 特長2
#### 3. 出来事を記録するごとに動物が仲間になります。全制覇が継続のモチベーション維持に。
