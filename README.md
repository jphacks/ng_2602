## 行き場のない気持ちに対する共感を目的としたWebアプリ
### 「他人の目を気にせずに気持ちを吐き出したい」<br>「行き場のない気持ちに対して誰かが共感してくれる場が欲しい」<br>そんな悩みを解決するWebアプリを、現代のSNSとは異なるアプローチから目指します。
### 共感してほしい出来事とそれに伴う感情を入力、日記として記録します。記録した出来事は任意で公開することができ、ユーザー間でリアクションをとることができます。
### 特長
#### 1.感情の見える化で自分の気持ちを整理
このWebアプリでは、日々の出来事やその時感じたことを日記として自由に記録でき、さらに10種類の感情から自分に当てはまるものを複数選択し、それぞれの強さを5段階で表現できることにより、感情を分類わけして記録できます。それにより、気づくことのできなかった複雑な感情に気づくことができます。また、感情の選択のみでも記録ができるため、自分のペースで気持ちを表現できます。記録をすると、選択した感情に応じた表情を持つ動物「ココロのコ」が誕生します。ココロのコに感情に応じた表情をしてもらうことによって、自分の気持ちを受け止めやすくなり他者にも伝えやすくなります。
#### 2.共感・肯定を中心とした匿名交流
自分が公開した日記に対して、他のユーザーは共感や肯定を表すスタンプのみでリアクションを送ることができます。あえてコメント機能を設けず、匿名で交流できる仕組みにすることで、他者からの批判や否定を恐れず、安心して自分の気持ちを共有できる環境です。
また、日記の詳しい内容を公開するかどうかをを自分で選択できるため、無理にすべてを打ち明ける必要がないためプライバシーを守りながら、自分のペースで気持ちを共有できる環境を実現しました。
#### 3.カレンダー機能による、感情の振り返りで自分自身の変化に気づく
記録した日記や感情は、カレンダー機能を使って日付ごとに振り返ることができます。カレンダーにはその日に誕生したココロノコが表示され、過去の出来事や、そのときに感じた感情の種類・強さを確認できます。また、タイムラインでは他者から自分の日記へのリアクション数は表示されず、種類のみがわかるようになっており、自らカレンダーで確認した時のみリアクション数が分かるため、落ち込んでいた日や楽しかった日など、日々の感情の移り変わりを振り返り、自分の心の変化に気づくきっかけをつくることが可能です。
### 解決出来ること
####
他人と比較して自分を否定的に捉え、悩みを一人で抱え込んでしまう人が、日記や感情の可視化を通じて自分の気持ちを整理し、理解できるようにします。また、共感・肯定を中心とした匿名交流によって、否定されることを恐れずに本音を共有できる場所を提供し、安心感をえることができます。
### 今後の展望
投稿しても反応がなければ、かえって孤独を感じてしまう可能性があるため、ココロのコから温かい言葉を受け取れる機能や、感情の変化を可視化する機能も充実させ、他者からの評価や反応に左右されず、ありのままの自分を受け入れられる場所を目指します。
### 注力したこと（こだわり等）
私たちは、**ユーザーが否定されることを恐れず、ありのままの感情を表現できること**を最も重視して開発しました。
特にこだわったのは、感情を動物のキャラクター「ココロのコ」として可視化する仕組みです。悲しみや怒りといったネガティブな感情も、親しみやすいキャラクターの表情として表現することで、自分の気持ちを受け止めやすくし、他者にも伝えやすくなるよう工夫しました。
また、安心して弱音を吐き出せる環境をつくるために、あえてコメント機能を設けず、共感・肯定のリアクションのみで交流する設計にしました。さらに、日記の詳しい内容を公開するかどうかを選択できるようにすることで、プライバシーを守りながら、自分が安心できる範囲で気持ちを共有できるようにしました。
このように、単に感情を記録・共有するだけでなく、**自分の感情を否定せずに受け止め、他者との比較ではなく共感によってつながれる体験**を実現することに注力しました。
